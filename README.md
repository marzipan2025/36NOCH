# 36NOCH

맥북 노치를 아이폰 다이내믹 아일랜드처럼 쓰는 개인용 macOS 앱. 집 맥과 회사 맥에서 같이 쓴다.

NotchNook(lo.cafe) 같은 완성품이 이미 있으므로, **NotchNook이 못 하는 내 것**(내 앱 상태, 작업 진행, 두 맥 사이 공유 등)을 노치에 띄우는 것이 목표다.
